# Sistema Integral de Gestión de Clientes, Servicios y Reservas

## 1. Descripción del proyecto

Este proyecto consiste en el desarrollo de un sistema integral de gestión de clientes, servicios y reservas utilizando el lenguaje de programación Python.

La aplicación implementa los principios de programación orientada a objetos, incluyendo abstracción, herencia, encapsulamiento y polimorfismo. También incorpora mecanismos de validación, manejo de excepciones y registro de eventos mediante archivos de logs.

## 2. Objetivo general

Desarrollar una aplicación modular en Python que permita administrar clientes, servicios especializados y reservas, aplicando los fundamentos de la programación orientada a objetos y las técnicas de control de errores.

## 3. Tecnologías utilizadas

* Python 3.
* Visual Studio Code.
* Git.
* GitHub.
* Programación orientada a objetos.

## 4. Estructura del proyecto

* `main.py`: archivo principal y ejecución de las pruebas.
* `entidades.py`: clase abstracta general del sistema.
* `clientes.py`: registro y validación de clientes.
* `servicios.py`: servicios especializados.
* `reservas.py`: administración de reservas.
* `excepciones.py`: excepciones personalizadas.
* `logs/`: almacenamiento de registros del sistema.
* `README.md`: documentación del proyecto.

## 5. Servicios implementados

El sistema contempla tres servicios especializados:

1. Reserva de salas.
2. Alquiler de equipos tecnológicos.
3. Asesoría especializada.

## 6. Funcionalidades principales

* Registro y validación de clientes.
* Administración de servicios.
* Creación y gestión de reservas.
* Confirmación y cancelación de reservas.
* Cálculo de costos, impuestos y descuentos.
* Validación de disponibilidad.
* Manejo de excepciones.
* Registro de eventos y errores.
* Demostración de polimorfismo.
* Ejecución de pruebas de funcionamiento.

## 7. Ejecución del proyecto

Para ejecutar el sistema se requiere tener Python 3 instalado.

Desde la terminal de Visual Studio Code, ejecutar:

`python main.py`

El sistema realizará automáticamente las operaciones de prueba y mostrará los resultados en la terminal.

## 8. Manejo de registros

Los eventos y errores del sistema se almacenan automáticamente en:

`logs/sistema.log`
